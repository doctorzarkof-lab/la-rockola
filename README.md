# La Rockola

Reproductor de musica de escritorio hecho en Java (Swing). Proyecto final de EDOO.
Las estructuras de datos estan hechas a mano: lista doblemente enlazada circular,
pila, tabla hash y lista de prioridad.

## Funciones
- Anade canciones desde un MP3 (el titulo y la duracion salen solos)
- Reproduce con pausa, siguiente, anterior y barra de progreso
- Historial, Mas Escuchadas, playlists y buscador

## Requisitos
- Java 17 o superior
- Tus propios archivos MP3 (no estan incluidos)

## Como usarlo
1. Descarga LaRockola.zip desde la seccion Releases.
2. Descomprimelo.
3. Windows: doble clic en LaRockola.bat. Linux: ./LaRockola.sh. Cualquier sistema: java -jar LaRockola.jar

## Como compilarlo
    git clone https://github.com/doctorzarkof-lab/la-rockola.git
    cd la-rockola
    ./construir.sh
